# 系统总览

AntFlowCore 的前端界面基于 Vue 3 + Element Plus 构建，采用若依（RuoYi）管理后台框架。系统界面分为顶部导航栏、左侧菜单栏和主内容区三部分。

## 界面布局

### 顶部导航栏

顶部导航栏包含以下元素：

- **Logo 和系统名称**：点击可返回首页
- **顶部菜单**：首页、流程中心等快捷导航
- **右侧功能区**：
  - 全屏切换按钮
  - 布局设置按钮
  - 主题模式切换（亮色/暗色）
  - 用户信息下拉菜单（个人中心、布局设置、退出登录）

### 左侧菜单栏

左侧菜单栏是系统的主要导航，包含以下功能模块：

| 菜单项 | 功能 |
|--------|------|
| 首页 | 系统概览，显示待办、已办等统计 |
| 流程中心 | 快捷跳转到任务中心各页面 |
| 任务中心 | 我的发起、撤销/退回、待办任务、已办任务、抄送到我 |
| 流程管理 | 流程监控、流程类型、流程设计 |
| 流程运维 | 委托设置、委托列表、消息模板、表单管理 |
| SaaS流程 | SaaS租户、应用管理 |
| 个人中心 | 布局设置、退出登录 |

### SaaS租户

管理多租户的SaaS流程配置。

![SaaS租户管理](/images/saas-tenant.png)

### 应用管理

管理流程关联的应用URL配置。

### 主内容区

主内容区显示当前页面的主要内容，包含面包屑导航和页面具体内容。

## 首页功能

系统首页（仪表盘）展示以下核心数据卡片：

- **我的待办**：当前用户的待办任务数量
- **今日已办**：当天已处理的审批数量
- **今日发起**：当天发起的流程数量
- **我的草稿**：保存在草稿状态的流程数量

首页还提供了以下快捷操作按钮：

- **访问码云**：跳转到 Gitee 仓库
- **流程设计器**：打开流程设计器（VForm）
- **飞书手册**：查看飞书文档
- **操作手册**：查看各类操作手册

![首页截图](/images/home.png)

## 任务中心

### 我的发起

展示当前用户发起的所有流程实例，支持按流程类型、状态、时间等条件筛选。

![我的发起页面](/images/my-initiate.png)

### 待办任务

展示当前用户需要审批的任务列表，点击可查看流程详情并进行审批操作（同意、拒绝、加批等）。

![待办任务列表](/images/todo-tasks.png)

### 已办任务

展示当前用户已经处理过的任务历史记录。

![已办任务列表](/images/done-tasks.png)

## 流程管理

### 流程监控

展示系统中所有流程实例的运行状态，管理员可以查看每个流程实例的当前节点、处理人、审批历史等信息。

### 流程类型

管理流程的分类信息，支持 LF（低代码）和 DIY（自定义）两种类型。

### 流程设计

进入流程设计器，可视化的流程建模工具。

## 流程运维

### 委托设置

用户可以设置审批委托，当用户不在时由委托人代为审批。

![委托设置页面](/images/entrust-settings.png)

### 委托列表

查看当前生效的委托关系。

![委托列表页面](/images/entrust-list.png)

### 消息模板

管理审批通知的消息模板，支持邮件、站内信、短信等多种通知方式。

![消息模板管理](/images/message-template.png)
