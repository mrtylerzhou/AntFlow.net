# 什么是 AntFlowCore

## 项目简介

AntFlowCore 是一个基于 .NET 10 的开源企业级低代码工作流引擎，旨在为开发者提供一个功能完善、易于扩展、开发成本低的工作流解决方案。它是对 Java 版 AntFlow 的 .NET 原生实现，采用现代化的 .NET 技术栈，支持多种数据库和多种部署方式。

AntFlowCore 将流程引擎的核心执行逻辑与业务处理逻辑完全分离，开发者无需深入了解 BPMN 规范即可快速上手工作流系统的开发。通过虚拟节点（VNode）模式和适配器（Adaptor）模式，实现了高度的可扩展性和可维护性。

## 核心设计理念

### 1. 虚拟节点（VNode）模式

AntFlowCore 首创虚拟节点模式，将流程引擎的执行 API 与业务流程处理高度分离。开发者不需要关心 BPMN 引擎的内部实现，只需要定义节点类型、节点属性和审批人规则，引擎自动处理流程流转。

### 2. 适配器模式

通过适配器模式将流程引擎流转业务和用户表单处理业务完全分离。DIY 流程后端只需实现一个接口即可快速上线，低代码流程拖拽即可完成。

### 3. 策略模式

按钮操作（同意、拒绝、加批、转办等）通过策略模式分发到对应的处理器，每个处理器独立负责一种操作，易于扩展和维护。

### 4. AOP 与中间件

通过 `TransactionalMiddleware` 实现自动事务管理，通过 `GlobalExceptionMiddleware` 实现全局异常处理，开发者无需在每个方法中手动编写 try-catch 和事务代码。

## 核心功能

### 流程设计
- 可视化流程设计器（BPMN 2.0）
- 14 种节点类型（串行、并行、会签、或签等）
- 14 种审批人规则
- 双层 AND/OR 条件规则
- 流程版本管理

### 流程运行
- 发起流程
- 审批操作（同意、拒绝、加批、转办、退回等）
- 流程预览
- 审批路径查看
- 流程委托与转办
- 消息通知

### 低代码
- 拖拽式表单设计
- 字段级权限控制（读/编辑/隐藏）
- 内联表单与外部表单
- 表单数据持久化

### 外部接入
- Open API
- 嵌入式接入
- 回调通知
- 多租户支持（SaaS）

## 与 Java 版 AntFlow 的关系

AntFlowCore 是 Java 版 AntFlow 的 .NET 原生实现，共享以下设计理念：

- 相同的 API 接口路径和参数格式
- 相同的前端界面（Vue 3 前端可同时对接两个后端）
- 相同的数据表结构（兼容现有数据）
- 相同的功能特性和业务流程

两者主要在技术实现层面存在差异，AntFlowCore 利用 .NET 10 和 FreeSql 等现代化工具，提供了更好的性能和更简洁的代码结构。

## 适用场景

AntFlowCore 适用于以下场景：

1. **企业内部 OA 系统**：请假、报销、采购等审批流程
2. **工单系统**：客服工单、IT 运维工单等
3. **项目管理**：任务审批、变更审批等
4. **第三方系统接入**：为其他系统提供审批能力
5. **SaaS 平台**：为多个租户提供独立的流程引擎服务
