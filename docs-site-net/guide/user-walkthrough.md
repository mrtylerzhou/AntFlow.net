# 用户操作手册

本文档面向最终用户，详细介绍如何使用 AntFlowCore 的审批流程功能。

## 登录系统

1. 打开浏览器访问系统地址
2. 在登录页面选择用户（下拉菜单）
3. 点击"登录"按钮进入系统

![登录页面](/images/login-page.png)

## 发起流程

### 低代码流程

1. 点击左侧菜单 **任务中心 → 我的发起**
2. 点击页面上的"新增"按钮
3. 选择流程类型
4. 填写表单内容
5. 点击"提交"发起审批

### 自定义表单流程

1. 点击左侧菜单 **任务中心 → 我的发起**
2. 点击"新增"按钮
3. 选择流程类型
4. 在弹出的外部表单中填写数据
5. 提交审批

## 审批操作

### 同意

1. 在待办任务列表中点击任务
2. 查看审批详情
3. 填写审批意见
4. 点击"同意"按钮
5. 流程自动流转到下一节点

### 拒绝

1. 在待办任务列表中点击任务
2. 查看审批详情
3. 填写拒绝原因
4. 点击"拒绝"按钮
5. 流程结束

### 加批

1. 在审批页面点击"加批"
2. 选择要加批的人员
3. 填写加批意见
4. 加批人员审批后，流程回到当前节点

### 转办

1. 在审批页面点击"转办"
2. 选择转办人员
3. 填写转办原因
4. 流程直接流转到转办人员

### 退回

1. 在审批页面点击"退回"
2. 选择要退回的节点（任意历史节点）
3. 填写退回原因
4. 流程回退到指定节点重新审批

## 流程预览

1. 在任务详情页面点击"流程预览"
2. 可以看到完整的流程图
3. 当前节点高亮显示
4. 已审批节点显示审批人信息
5. 未审批节点显示待处理人信息

## 流程委托

### 设置委托

1. 点击左侧菜单 **流程运维 → 委托设置**
2. 点击"新增"按钮
3. 选择委托人
4. 设置委托时间范围
5. 选择要委托的流程类型
6. 保存

### 查看委托

1. 点击左侧菜单 **流程运维 → 委托列表**
2. 查看所有委托关系
3. 可以编辑或删除委托

## 消息通知

审批相关的通知通过以下方式发送：

- **站内信**：登录后在消息中心查看
- **邮件**：发送到用户邮箱
- **短信**：发送到用户手机（需配置）

## 常见问题

**Q: 如何查看审批进度？**
A: 进入"我的发起"列表，点击具体流程可查看审批路径图。

**Q: 如何撤回已发起的流程？**
A: 进入"撤销/退回"列表，选择流程后点击"撤回"。

**Q: 审批人不在怎么办？**
A: 审批人可以提前设置委托，或者管理员可以在流程监控中变更处理人。

**Q: 审批人无法看到待办任务？**
A: 请检查流程配置中的审批人规则是否正确，或联系管理员检查流程状态。
