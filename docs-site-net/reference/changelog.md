# 更新日志

## 版本说明

AntFlowCore 遵循语义化版本规范（SemVer）：`主版本.次版本.修订号`

- **主版本**：不兼容的 API 修改
- **次版本**：向下兼容的功能新增
- **修订号**：向下兼容的问题修正

## [1.0.0] - 2024-01-15

### 核心功能
- **流程引擎**：基于虚拟节点模式的流程流转引擎
- **BPMN 支持**：支持开始事件、用户任务、排他网关、并行网关、结束事件
- **审批操作**：同意、拒绝、驳回、加签、转办、变更处理人
- **会签模式**：或签、会签、顺序会签
- **条件引擎**：基于策略模式的双层 AND/OR 条件评估

### 审批人规则
- 指定人员
- 指定角色
- 发起人直属领导
- 发起人部门负责人
- HRBP
- 层层审批
- 指定层级审批
- 发起人自选
- 表单关联人员
- 表单关联角色
- 表单关联人员直属领导
- 自定义规则（UDR）
- 部门负责人
- 指定部门

### 表单支持
- 低代码表单（JSON Schema 驱动）
- DIY 自定义表单（适配器模式）
- 字段级权限控制（R/E/H）
- 内联表单与外部表单

### 技术栈
- .NET 10
- FreeSql ORM
- Natasha 动态编译
- Serilog 结构化日志
- JWT 认证

### 数据库支持
- MySQL 5.7+
- PostgreSQL 12+
- SQL Server 2019+

## 版本迁移指南

### 从 0.x 迁移到 1.0

1. **数据库变更**：
   ```sql
   -- 1.0 新增表
   CREATE TABLE bpmn_conf_lf_formdata (...);
   CREATE TABLE bpm_process_draft (...);
   ```

2. **配置变更**：
   ```json
   {
     "FeatureFlags": {
       "LowCodeForm": true,
       "MultiTenant": true
     }
   }
   ```

3. **API 变更**：
   - `/api/lowcode/*` 为新增接口
   - `/api/BpmnConf/Edit` 请求体结构调整

4. **代码变更**：
   - 实体类命名空间调整
   - 服务接口签名变更
