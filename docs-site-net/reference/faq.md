# 常见问题

## 安装部署

### Q: AntFlowCore 需要什么版本的 .NET？

A: AntFlowCore 基于 .NET 10 构建，需要安装 .NET 10.0 SDK 或更高版本。运行时可以使用 .NET 10.0 ASP.NET Core Runtime。

### Q: 支持哪些数据库？

A: 完全支持 MySQL（5.7+）、PostgreSQL（12+）、SQL Server（2019+）。理论上支持 Oracle（12c+）和 SQLite（3.x），但推荐在生产环境使用前三种。

### Q: 如何初始化数据库？

A: AntFlowCore 使用 FreeSql CodeFirst 模式，首次启动时会自动根据实体类创建表结构。确保配置了 `IsAutoSyncStructure: true` 且有足够的数据库权限。

### Q: Docker 部署时区不正确怎么办？

A: 在 docker-compose.yml 中添加环境变量：
```yaml
environment:
  - TZ=Asia/Shanghai
volumes:
  - /etc/localtime:/etc/localtime:ro
```

## 流程设计

### Q: 如何创建一个新流程？

A: 基本步骤：
1. 创建表单码：`POST /lowcode/createLowCodeFormCode`
2. 设计表单：通过 vform 设计器生成 JSON
3. 配置流程节点：在流程画布上拖拽审批节点
4. 关联表单与流程：在流程配置中设置 formCode
5. 生效流程：`GET /BpmnConf/effectiveBpmn/{id}`

### Q: 流程模板生效后还能修改吗？

A: 直接修改已生效的模板会影响进行中的流程。建议：
1. 创建新版本模板
2. 新发起的流程使用新版本
3. 进行中的流程继续使用旧版本

### Q: 如何实现会签？

A: 在审批节点配置中设置"会签"模式：
- **或签**：任一审批人同意即通过
- **会签**：所有审批人同意才通过
- **顺序会签**：按顺序依次审批，全部同意才通过

### Q: 审批人怎么从表单中选取？

A: 使用"表单关联"审批人类型。配置步骤：
1. 在表单中定义人员选择字段（如 `manager_id`）
2. 在节点审批人配置中选择"表单中的人员"
3. 选择对应的表单字段名

### Q: 条件分支如何配置？

A: 在排他网关（Exclusive Gateway）后的连线上配置条件：
```json
{
  "conditionType": "lowcode_field",
  "fieldKey": "amount",
  "operator": ">",
  "value": "1000",
  "logic": "AND"
}
```

## 表单相关

### Q: 低代码表单和 DIY 表单有什么区别？

A: 
- **低代码表单**：通过拖拽设计器创建，数据存储在 JSON 中，适合标准审批场景
- **DIY 表单**：前端自由开发，数据存储在自定义表中，适合复杂业务场景

详见 [低代码 vs 自定义表单对比](../lowcode/lowcode-vs-diy.md)

### Q: 表单字段如何参与条件判断？

A: 表单中的字段在条件中通过 `formCode.fieldKey` 引用。例如请假天数大于 3 天需要上级审批：
```
leave_form.days > 3
```

### Q: 如何实现字段级权限控制？

A: 在流程节点的表单属性中，为每个字段设置权限：
- **R** (ReadOnly)：只读
- **E** (Editable)：可编辑
- **H** (Hidden)：隐藏

### Q: 表单支持文件上传吗？

A: 支持。使用 BLOB 类型字段，前端使用文件上传组件。文件以二进制形式存储在数据库中，或配置为存储到文件系统/OSS。

## 审批操作

### Q: 审批操作有哪些类型？

A: 支持以下操作：
- **同意** (agree)：审批通过，流程继续
- **拒绝** (disagree)：审批不通过，流程终止
- **驳回** (reject)：退回到上一节点
- **加签** (addSign)：在当前节点添加额外审批人
- **转办** (transfer)：将任务转给其他人处理

### Q: 驳回可以回到任意节点吗？

A: 是的。AntFlowCore 支持驳回至流程中的任意历史节点，不仅限于上一节点。

### Q: 如何实现审批委托？

A: 通过委托功能实现：
1. 在委托管理中设置委托人、被委托人、有效期
2. 委托期间，委托人的待办自动转发给被委托人
3. 被委托人以委托人身份处理审批

### Q: 审批人去重是如何工作的？

A: 当同一人在流程的不同节点都可能是审批人时，系统会自动去重：
- 串行节点：如果当前审批人已经审批过，自动跳过
- 并行节点：同一人只需审批一次

## 性能优化

### Q: 流程启动慢怎么办？

A: 排查方向：
1. 检查是否有复杂条件计算
2. 审批人规则是否涉及大量数据查询
3. 是否开启了流程预览图生成
4. 数据库连接池是否充足

### Q: 大量并发时如何优化？

A: 建议：
1. 启用读写分离
2. 添加流程配置缓存
3. 优化数据库索引
4. 使用 Redis 缓存热数据
5. 考虑水平扩展 API 服务

### Q: 流程图渲染卡顿怎么办？

A: 当节点数量超过 50 个时：
1. 前端使用 Canvas 替代 SVG 渲染
2. 启用虚拟滚动，只渲染可视区域
3. 简化连线样式

## 集成开发

### Q: 如何接入现有用户系统？

A: 实现 `IUserEntrustService` 接口，提供：
- 用户信息查询
- 角色信息查询
- 组织架构查询
- 直属领导查询

### Q: 如何与外部系统集成？

A: 提供两种方式：
1. **Open API**：通过 REST 接口提交和查询流程
2. **嵌入式**：将审批组件嵌入到业务系统中

### Q: 如何接收流程状态变更通知？

A: 实现回调接口：
```csharp
public interface ICallbackAdaptor
{
    Task OnProcessCompleted(string processNumber, string result);
    Task OnTaskCreated(string processNumber, string taskInfo);
}
```

### Q: 支持多租户吗？

A: 支持。通过 `TenantId` 实现数据隔离：
- 每个请求携带租户标识
- 数据库查询自动过滤租户数据
- 支持独立数据库或共享数据库模式

## 故障排查

### Q: 启动时数据库连接失败？

A: 检查清单：
1. 数据库服务是否运行
2. 连接字符串是否正确
3. 数据库是否已创建
4. 防火墙是否开放端口
5. 用户名密码是否正确

### Q: 流程流转卡住不继续？

A: 可能原因：
1. 下一节点审批人未配置或配置错误
2. 条件判断未匹配任何分支
3. 流程实例状态异常
4. 数据库事务未提交

### Q: 日志在哪里查看？

A: 默认日志位置：
- **控制台**：直接输出到终端
- **文件**：`logs/app-YYYYMMDD.log`
- **Seq**：`http://localhost:5341`（如果配置了）

### Q: 如何开启详细日志？

A: 修改 `appsettings.json`：
```json
{
  "Serilog": {
    "MinimumLevel": {
      "Default": "Debug"
    }
  }
}
```

## 安全相关

### Q: 如何保护 API 接口？

A: 推荐措施：
1. 使用 JWT Token 认证
2. 启用 HTTPS
3. 配置 CORS 白名单
4. 启用请求限流
5. 敏感数据加密存储

### Q: 审批数据如何保证安全？

A: 多层防护：
1. 传输层：HTTPS 加密
2. 存储层：敏感字段加密
3. 访问层：基于角色的权限控制
4. 审计层：操作日志完整记录

### Q: 如何防止越权操作？

A: AntFlowCore 内置防护：
1. 任务操作时验证当前用户是否为处理人
2. 数据查询时自动过滤非授权数据
3. 管理员操作需要额外权限验证
